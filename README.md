# Data Automation & Analytics Environment (Python & MySQL)

A Python-based workspace for data scraping, cleaning, and automation. I use this repo to build and test real workflows for pulling data from the web, transforming it into something usable, and loading it into a database — the kind of work I do for freelance/client projects.

## What's in here

### `netflix-tmdb-tracker`
Pulls and enriches movie/show data from streaming catalogs (Netflix/TMDB). Combines scraping and API calls, then cleans and structures the result so it's ready to analyze or drop straight into a database.

**Stack:** Python, Pandas, requests / API integration

### `core-scripts`
Baseline scripts and experiments — things like reusable cleaning functions, small automation tasks, and setup utilities I build on for larger projects.

## Tech stack

- **Language:** Python
- **Data processing:** Pandas, NumPy
- **Database:** MySQL
- **Tools:** Jupyter Notebook, Git

## Getting started

```bash
git clone https://github.com/NeuralK/python_project.git
cd python_project
pip install -r requirements.txt
```
